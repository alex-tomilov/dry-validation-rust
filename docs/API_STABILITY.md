# API stability

This is the authoritative inventory of Ruby interfaces that YARD currently
reports as non-private. It was generated for `0.1.0.pre5` with:

```sh
bundle exec yard --list --query "@api.text != 'private'"
```

The inventory makes the support boundary in [API_BOUNDARY.md](API_BOUNDARY.md)
actionable. `stable` entries are part of the supported side-by-side API and
follow the versioning policy in [SUPPORT_MATRIX.md](SUPPORT_MATRIX.md).
`experimental` entries are reachable Ruby implementation hooks with no
compatibility promise. `deprecated` entries are the exact-compatibility shim;
new code must use the side-by-side namespace instead.

YARD's query presently includes some members whose enclosing type or adjacent
documentation is marked `@api private` (notably `Macro`, `PathTrie`, and
`Schema::Predicate`). They are explicitly classified as experimental here; the
listing does not turn them into supported APIs.

When a public API changes, update this inventory and its adjacent YARD
documentation in the same change.

| `Dry::Schema`     | class; `RUST_COMPATIBILITY_LAYER`, `VERSION`, `.Params`, `.JSON`, `.define`                                                      | deprecated | 0.1.0.pre1    | Requires `dry/schema`; owned by the exact-compatibility shim.                  |

The deprecated entrypoints are excluded from the public compatibility guarantee.
See [MIGRATION_FROM_EXACT_MODE.md](MIGRATION_FROM_EXACT_MODE.md) for the
supported migration path.
